  <action>Rewrite relay-handler. Env: TUNNELS_TABLE, CONNECTIONS_TABLE, LOGS_TABLE (all granted). Entry shape (Lambda URL): event.requestContext.http.method, event.rawPath, event.rawQueryString, event.headers (lowercase keys), event.body, event.isBase64Encoded.

Flow:
1. subdomain = host from event.headers.host: strip trailing '.' + 'vole.sh' (config via env DOMAIN='vole.sh'), lowercase, must match /^[a-z0-9-]+$/ else 400.
2. GetItem TUNNELS_TABLE {subdomain}. Missing → 404 {error: 'no such tunnel'}.
3. GetItem CONNECTIONS_TABLE {connectionId: tunnel.connectionId}. Missing → 404 {error: 'tunnel offline'}.
4. Build request payload: {id: randomUUID(), method, path: rawPath, query: rawQueryString || undefined, headers: {content-type, ...} — forward only safe headers (content-type, accept, accept-*, cookie, user-agent, authorization, x-*); skip hop-by-hop (host, content-length, connection, transfer-encoding, content-encoding? keep content-encoding only if body present and base64). bodyB64: if body && !isBase64Encoded → Buffer.from(body,'utf8').toString('base64'); if isBase64Encoded → body as-is; body bytes > CHUNK_SIZE → send request frame WITHOUT bodyB64 but with chunkTotal, then one data frame per chunk (CHUNK_SIZE slices), total ≤ 10MB else 413 before posting.
5. Put LOGS_TABLE item {connectionId, requestId: id, method, path, status: 'pending', createdAt, expiresAt: now+60000}.
6. Post request frame(s) to connection (ApiGatewayManagementApiClient same pattern as ws-handler; GoneException → 404). If post fails (connection dead) → delete tunnel row, 404.
7. Poll: every 300ms GetItem LOGS_TABLE {connectionId, requestId: id} until response present (status 'done') or 30s elapsed → 504 {error: 'tunnel timeout'}. On done: read response {statusCode, headers, bodyB64, chunkTotal}; if chunkTotal > 0 → Query LOGS_TABLE sk begins_with id + '#', collect items ordered by n, assembleBody, delete chunk items; else bodyB64.
8. Return streamed response: {statusCode, headers: {...response.headers, content-type (default text/html; charset=utf-8), content-length}, body: Readable.from([Buffer.from(body, 'base64')])} — import { Readable } from 'node:stream'; invocation mode is RESPONSE_STREAM (already set in stack). Delete the request item after reading.
9. 405 for methods other than GET/POST/PUT/PATCH/DELETE/OPTIONS/HEAD; HEAD: forward as GET to CLI, strip body.
Errors: 400/404/413/504 JSON {error}. Log requestId + subdomain + status only.

Keep handler fast: early returns, no await before needed. No comments.</action>
