  <action>cli/src/tunnel.ts: class TunnelSession. Constructor {server, token}. connect(): WebSocket(server.replace(/^http/,'ws') + '?token=' + encodeURIComponent(token)). onopen → send helloFrame(1). onmessage → parseFrame; dispatch:
  - ready → send tunnel-open frame {type, localPort}
  - tunnel-open → resolve openPromise with d.subdomain + url; print 'Vole tunnel online: https://<subdomain>.vole.sh -> http://localhost:<port>'
  - pong → heartbeat ack (no-op)
  - error → print d.error
  - request → callback to http.ts handler
  - data → buffer into pendingChunks map by id: chunks[n] = d.data; when n+1 === expectedTotal (from request d.chunkTotal) assemble
  onclose → print 'connection closed' exit 1 (reconnect is v2). heartbeat: setInterval 240s → send pingFrame(). close(): send tunnel-close {subdomain} if open, ws.close(), clearInterval.
  Use global WebSocket (Node 22+/Bun). onmessage handler must process frames sequentially (simple queue or await chain — WS 'message' events may interleave with awaits: implement per-request async queue: store a promise chain `chain = chain.then(handle)`).

cli/src/index.ts: 'http' → runHttp: port = parseInt(argv[0] || '3000'); config = loadConfig(); no token → 'Run: vole authtoken <token> <wss-url>' exit 2; server = config.server || env VOLE_SERVER || error 'no server configured'. Delegate to commands/http.ts.</action>

  <action>commands/http.ts: export async function runHttp(port, session). Attach request handler to session. For each request frame {id, method, path, query, headers, bodyB64?, chunkTotal?}:
  1. body: bodyB64 ?? (chunkTotal > 0 ? await session.waitChunks(id, chunkTotal) : '').
  2. target = 'http://localhost:' + port + path + (query ? '?' + query : ''); headers: forward {content-type, accept, cookie, user-agent, authorization, ...} excluding hop-by-hop.
  3. fetch(target, {method, headers, body: body ? Buffer.from(body, 'base64') : undefined, redirect: 'manual', signal: AbortSignal.timeout(25_000)}).
  4. On fetch error → response frame {statusCode: 502, headers: {content-type: application/json}, bodyB64: Buffer.from(JSON.stringify({error: 'local server unreachable'})).toString('base64')}.
  5. Success: res = await fetch; bodyBuf = Buffer.from(await res.arrayBuffer()); if bodyBuf.length === 0 → response frame without body; if ≤ 90KB → response frame {statusCode: res.status, headers: safeResponseHeaders(res.headers), bodyB64}; else → response frame {statusCode, headers, chunkTotal} + send dataFrame(id, n, chunkB64) for each chunk from splitBody. Safe headers: exclude content-length, connection, transfer-encoding, keep-alive, content-encoding (body re-encoded as base64 — re-encoded means content-encoding no longer valid; drop it, note).
  6. Send via session.send(encodeFrame(...)). All sends await a per-connection write queue (serialize to preserve order with chunks).
  HEAD: relay already strips body server-side; CLI forwards as-is.
  Print one line per request: 'GET /path -> 200 (123B)' to stderr.</action>
